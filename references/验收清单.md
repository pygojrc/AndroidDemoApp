# 验收清单

## 静态与构建验证

- [ ] `SKILL.md` 通过 Skill 校验器。
- [ ] `agents/openai.yaml` 的能力说明与 Skill 一致。
- [ ] Demo 没有动态依赖版本。
- [ ] Demo 不存在 `res/layout/`。
- [ ] `minSdk` 为 33，`compileSdk` 和 `targetSdk` 为已验证版本。
- [ ] `./gradlew :app:assembleDebug` 成功。
- [ ] `./gradlew :app:lintDebug` 成功。
- [ ] `app-debug.apk` 存在且能够读取包名、SDK 和签名信息。
- [ ] 使用指定 Debug Key 签名。
- [ ] 项目创建脚本生成的新工程能够再次构建。

## UI 结构检查

- [ ] 首页、输入和设置三个底部导航项存在。
- [ ] 再次点击当前导航项不会重复创建页面。
- [ ] 从输入或设置页面按返回键返回首页。
- [ ] 页面应用并消费 Scaffold 的 `innerPadding`。
- [ ] 输入页面包含真实 TextField 和 IME Insets 处理。
- [ ] 浅色、深色和动态配色代码路径存在。
- [ ] adaptive、round 和 monochrome 图标资源完整。

## 设备验证

有可用 Android 13+ 模拟器或真机时追加：

- [ ] 安装并冷启动 APK。
- [ ] 依次切换三个页面。
- [ ] 检查状态栏、挖孔和导航栏是否遮挡内容。
- [ ] 打开输入页面并弹出软键盘，检查当前输入项和底部按钮。
- [ ] 切换浅色和深色模式。
- [ ] 检查横屏和不同窗口宽度。
- [ ] 检查普通图标和 Android 13 themed icon。

构建成功只表示编译验证通过；没有实际安装和操作时，不得报告模拟器或真机验证通过。
